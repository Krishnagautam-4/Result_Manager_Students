# 🎓 Student Result Manager

A simple Python command-line application for managing student records and checking student results.

## ✨ Features

✅ Add student records and marks

📋 View all students and their marks

🔍 Check whether a student has passed or failed

🖥️ Easy-to-use menu-driven interface

📚 Uses Python dictionaries for data storage

## 🛠️ Technologies Used

* Python 3

## 🚀 How to Run

1. Clone this repository:

```bash
git clone <repository-url>
```

2. Navigate to the project folder:

```bash
cd student-result-manager
```

3. Run the program:

```bash
python main.py
```
